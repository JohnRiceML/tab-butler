# docs/public — publishable versions of Goobi's research docs

This folder holds standalone, public-facing versions of Goobi's research documents — written so
they can be posted outside the repo (blog, docs site, gist) without leaking product internals.
The public docs keep the per-claim provenance tags (they are the credibility) but deliberately
exclude Goobi's encoding map, tuning constants, eval results, and watch checklists, which live
in the internal `docs/` and stay private. **Nothing here is auto-published**: putting any of
these files anywhere public is a deliberate owner action, made file-by-file.
