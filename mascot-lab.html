Free motion — one sprite, CSS transforms

Animate the whole sprite with translate / rotate / scale — no extra art. Idle, bounce, spin, tada all live here. The trick: transform‑origin: bottom center, so it moves like it's standing on the ground.

02

Frame‑by‑frame — swap pixel frames

When features move — eyes, legs, arms — redraw a few pixel frames on a timer with uneven holds for rhythm. Blinks, winks, tears, and waves all just repaint the relevant pixels, and stack on top of a CSS bob.
